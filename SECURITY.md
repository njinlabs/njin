# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in njin, please report it privately. Do not open a public issue or pull request.

Use GitHub's private reporting: go to the [Security tab](https://github.com/njinlabs/njin/security) of the repository and choose **Report a vulnerability**.

Please include what you found, how to reproduce it, and the version of njin you tested. We will acknowledge your report, keep you updated while we work on a fix, and credit you in the release notes if you wish.

## Supported versions

Security fixes are released for the latest stable version of njin.
